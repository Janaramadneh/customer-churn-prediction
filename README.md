# Customer Churn Prediction

This project predicts customer churn using machine learning techniques.

## Tools & Libraries
- Python
- Pandas
- Scikit-learn

## Steps
1. Data cleaning and preprocessing
2. Encoding categorical variables
3. Splitting dataset into training and testing sets
4. Training a Random Forest Classifier
5. Evaluating the model with accuracy and confusion matrix

## Results
- Accuracy: ~80-85%
- Successfully predicts which customers may leave

## Dataset
- Telco Customer Churn dataset
